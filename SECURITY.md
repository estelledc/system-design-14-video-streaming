# Security policy

This repository is an educational, synthetic video-publication slice. Do not use it for real user media or production traffic.

Report a suspected vulnerability through GitHub's private vulnerability-reporting channel when available. Do not include real
media, credentials, personal data, or exploit traffic in an issue.

The intended tests cover bounded input, ownership, upload integrity, worker fencing, atomic manifest publication, immediate
read denial after a tombstone, log minimization, and dependency advisories. They do not establish DRM, malware detection,
copyright compliance, content moderation, privacy compliance, CDN isolation, or production hardening.
